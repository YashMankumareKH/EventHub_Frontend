# EventHub React Frontend

A comprehensive event management system built with React and Vite.

## 🚀 Features

### User Roles

#### Participant (User)
- Browse and search published events
- View detailed event information
- Register for events
- View upcoming and completed events
- Manage personal profile
- Cancel event registrations

#### Event Manager
- Create and manage events
- Update event details
- View attendee lists
- Cancel user registrations
- Cancel or delete events
- Track event capacity

#### Admin
- User management (view, create, update, deactivate)
- Event management (view all, deactivate)
- Manager oversight
- System statistics dashboard

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Java backend running on `http://localhost:8080`

## 🛠️ Installation

### 1. Create Project

```bash
npm create vite@latest eventhub-frontend -- --template react
cd eventhub-frontend
```

### 2. Install Dependencies

```bash
npm install react-router-dom axios lucide-react
```

## 📱 Application Flow

### 1. Registration & Login
- New users can register as Participant or Manager
- Existing users log in with email and password
- Role-based dashboard redirection

### 2. Participant Flow
1. Browse events on home page
2. Search and filter events
3. View event details
4. Register for events
5. View upcoming/completed events in dashboard
6. Manage profile
7. Cancel registrations

### 3. Manager Flow
1. Access manager dashboard
2. Create new events with full details
3. View and manage created events
4. Edit event information
5. View attendee lists
6. Cancel user registrations
7. Cancel or delete events

### 4. Admin Flow
1. View system statistics
2. Manage all users (create, update, deactivate)
3. Oversee all events
4. Deactivate problematic events
5. View manager activities

## 🐛 Troubleshooting

### CORS Issues
Make sure your backend has CORS enabled for `http://localhost:5173`

### API Connection
Verify backend is running on `http://localhost:8080`

### Build Errors
```bash
# Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Port Already in Use
```bash
# Kill process on port 5173
npx kill-port 5173
```

## 📝 Code Structure

### Component Organization
- **Common**: Reusable UI components
- **Auth**: Authentication forms
- **User**: Participant-specific components
- **Manager**: Event management components
- **Admin**: Administration components

### State Management
- **Context API**: Global auth state
- **Local State**: Component-specific data
- **API Calls**: Centralized in service layer

### Routing
- **Public Routes**: Home, Events, Login, Register
- **Protected Routes**: Dashboards based on role
- **Role-Specific**: Admin, Manager, User routes
