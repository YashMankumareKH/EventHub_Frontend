# EventHub React Frontend - Complete Project Structure

## Project Setup

```bash
npm create vite@latest eventhub-frontend -- --template react
cd eventhub-frontend
npm install
npm install react-router-dom axios lucide-react
npm run dev
```

## Installation Commands

```bash
# Core dependencies
npm install react-router-dom axios

# UI components (optional)
npm install lucide-react

# Development
npm install -D @vitejs/plugin-react
```

## Environment Variables (.env)

```env
VITE_API_BASE_URL=http://localhost:8080
```

---

## Implementation Notes

1. **Authentication Flow**: Uses Context API for global auth state
2. **API Layer**: Centralized axios configuration with interceptors
3. **Routing**: Protected routes based on user roles
4. **State Management**: React Context + local component state
5. **Styling**: Can use Tailwind CSS or regular CSS modules
